# 🎬 Amazon Prime Video – Exploratory Data Analysis

## 📌 Project Overview

This project performs an **Exploratory Data Analysis (EDA)** of Amazon Prime Video content using Python.

The analysis explores the available movies and TV shows based on attributes such as **content type, release year, ratings, genres, popularity, votes, cast, and crew**.

The goal is to clean the raw datasets, understand the structure of the content library, identify patterns, and present findings through meaningful visualizations.

---

# 🎯 Objectives

- Understand the structure of Amazon Prime Video datasets
- Clean and preprocess raw data
- Handle missing values and duplicate records
- Analyze movies and TV shows
- Explore content distribution by year
- Analyze IMDb and TMDb ratings
- Study votes and popularity
- Explore genres and content categories
- Analyze cast and crew information
- Create meaningful visualizations from the data
- Extract useful patterns and insights from the datasets

---
